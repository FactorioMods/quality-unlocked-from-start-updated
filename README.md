# Quality Unlocked from Start: Updated

Unlock higher quality tiers and recycling at the start of a Space Age game.

**Factorio 2.1 · Version 1.0.2**

## Fork changes

- Supports Factorio 2.1.
- Gives newly created forces the same quality and recycling unlocks as existing forces, including teams added during an ongoing game.

The original four higher-quality unlocks and recycler recipe without a planet restriction are retained. Other progression mods may alter requirements.

## Installation

Requires Space Age. Disable `quality-unlocked-from-start` before enabling this fork.

Factorio 2.1.24 checks covered fresh-force unlocks and recycler crafting at Nauvis/Vulcanus pressures. [Validation and earlier connected-client checks](FACTORIO-2.1.md).
